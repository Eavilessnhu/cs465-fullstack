# cs465-fullstack
CS-465 Full Stack Development with MEAN

While I was building this full-stack application, I was able to demonstrate how distinct front-end and back-end work integrate through standard data formats. The admin dashboard utilized an Angular Single-Page Application (SPA) that can deliver dynamic, client-side routing and seamless UI state updates without having full page refreshes. MongoDB was the database used in the back-end due to how flexible this NoSQL model handles BSON natively.

Securing and verifying the architecture required API testing through all endpoints using tools like Postman to validate status codes, payload structures, and error handling.
When implementing JSON Web Token (JWT) authentication and middleware introduced security challenges that requires both authorized requests containing valid Bearer headers and unauthenticated requests to make sure unauthorized access was rejected.
